> Status atual: **em andamento**, com conteúdo sendo adicionado conforme avanço nos estudos.

Repositório estruturado e em constante evolução, documentando minha trajetória de estudos em Java, desde os fundamentos da linguagem até Orientação a Objetos, Collections, tratamento de exceções e APIs REST com Spring Boot.

## Propósito

Este repositório existe para:

1. acompanhar minha própria evolução no aprendizado de Java e Back-End;
2. juntar teoria, exercícios e exemplos práticos em um único lugar organizado;
3. colocar em prática o que estudo através de pequenos projetos;
4. ter um material de consulta para revisar tópicos mais à frente;
5. mostrar de forma transparente meu processo de aprendizado, caso alguém avalie meu portfólio.

## Tópicos estudados

- **Fundamentals**: sintaxe básica, tipos primitivos, operadores, entrada/saída de dados, estruturas de controle (if/else, switch, for, while, do-while), arrays e métodos.
- **OOP (Orientação a Objetos)**: classes, atributos, construtores, encapsulamento, herança, sobrescrita de métodos, polimorfismo, interfaces e classes abstratas.
- **Collections e Exceptions**: Collections Framework (List, Map, Set e suas implementações) e tratamento de exceções (try/catch/finally, exceções customizadas, boas práticas).
- **Spring Boot**: introdução ao framework para desenvolvimento de APIs REST, controllers, endpoints, camadas da aplicação (controller, service, repository) e injeção de dependência (@Autowired, @Service, @Repository, @Component).

## Objetivos de aprendizado

- Ter uma base sólida nos fundamentos da linguagem Java;
- Entender bem os pilares da Orientação a Objetos na prática;

- Conseguir construir APIs REST com Spring Boot com confiança;
- Fechar cada etapa com pelo menos um projeto pequeno aplicando o que foi aprendido.
